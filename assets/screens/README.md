# Application screens

Actual current offline renderer output with illustrative project data. These are
not photographs of hardware. Mikro images also represent Mikro MK2; dual
monochrome screens represent MK1/MK2, color screens MK3/Maschine+ controller mode.
No factory audio or third-party sample files are bundled with these images.

Regenerate from the manual render catalog with `python3 -m tools.build_public_gallery`.
