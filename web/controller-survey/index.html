USB-MIDI inputs are detected after permission. Matching ports are suggested; select the ports belonging to this controller. Only selected inputs are recorded. No MIDI output is sent.

Start your guided mapping

Start mapping shows the display tests first. Confirm the pictures, then follow the control prompts. Press and release each button once; turn each encoder clockwise through a few steps. Controls advance automatically after release or after turning stops. LED identification follows, then a CHECK COMPLETE screen.

Starting allows fixed display test images, on-device instructions, temporary display lighting on supported models, and the LED tests. Unknown or inaccessible displays can be skipped explicitly; their status remains untested.

Missing a physical control?

Add every control missing from the list. For an encoder, add separate clockwise and counterclockwise entries. Do not count a SHIFT label as a second physical button.

4 · LED identification

One light or color channel is enabled at a time. Press the illuminated button or pad and release it. On unknown layouts, identify the lit item below and confirm. A correct input mapping is needed for automatic identification. If nothing lights up, use No light / unavailable.
