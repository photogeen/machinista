PLAY YOUR PROGRESSIONS

Custom Chords

Import MPC .progression or Ripchord .rpc presets. Each pad plays one chord; MIDI keys use the preset's original input mappings.

Your chord library

Up to 128 chords · 32 notes per chord · 1 MiB per file

On the controller: Keyboard → Chord Mode CUSTOM → Preset. Encoder 4 selects a preset on MK2. Use Pad Bank for the next 16 chords; the next parameter page has velocity variations. MIDI notes are numbered 0–127 (60 = middle C). Presets copied into a project stay with that project; reselect a preset to use library edits.

FOUR OSCILLATORS · YOUR SOUND

Machinista Synth

Select a Sound with Machinista Synth on the controller.

Load Machinista Synth on a Sound, then select that pad. The editor follows your selected Sound.

Edits are heard immediately on the selected Sound. Play its pads or keyboard to audition. Save Sound keeps the entire patch, waves and effects. Use the controller to record parameter automation.

Synth waveforms

Machinista Synth includes 32 original wave sources. Import your own single-cycle or wavetable WAVs, then choose them on OSC 1–4. Save the current Sound to keep the patch and its waves together.

Mono PCM 16/24/32-bit or 32-bit float WAV · 1–256 cycles · up to 32 MiB. Longer recordings must first be trimmed to a complete cycle. Uploads retain relative frame levels.

EFFECTS & INSTRUMENTS

LV2 Plugins

Upload a compiled Linux LV2 bundle. The Pi checks its architecture, required libraries and LV2 metadata before activation.

Install your plugins

ZIP, TAR.GZ, TGZ or TAR containing complete .lv2 folders · up to 128 MiB

Only install plugins you trust. Compatible uploads activate when playback and recording are stopped. No audio processing is started by the check.

Removing a bundle removes all plugins inside it. Bundles used by the current project cannot be removed. Saved projects keep their plugin references.

Preset banks

Import Dexed DX7 banks or single voices (.syx), older OB-Xd 2 banks (.fxb), individual OB-Xd patches (.fxp), RaffoSynth single patches (.dat), or Machinista JSON banks. Unzip downloaded sound packs first. On the controller, open the instrument's first parameter page and choose BANK and PATCH. Current projects keep their saved patch parameters when a bank is removed.

OPTIONAL INSTRUMENT

VirtualJV · JV-880

Select VirtualJV on a Sound first, then choose its bank and patch below. Stop transport before applying. Bank changes prepare in the background. Save the current Sound to keep the patch and plug-in strip.

ROM management

Uses your own ROM files. Original ROMs stay separate from plugin downloads. This emulator add-on has a noncommercial license and is not included in clean Machinista images.
